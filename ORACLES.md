# Frozen independent oracles — before implementation, October 5, 2026

These values are hand-calculated from the approved declared model, not generated by its implementation. All deltas below are 1 unless stated, same caller/operation/intent and key K; times ordered and retention 10 ms unless stated. Each request has a fresh attempt ID.

| Case | Script | Requests / accepted / effects | Generated / delivered | Other expected result |
|---|---|---|---|---|
| unprotected-loss | request A, success A dropped, request B, success B delivered | 2 / 2 / 2 | 2 / 1 | counter=2; intent repeat=1; A client unknown |
| atomic-loss | same script but retained key; omit completion B because replay not active | 2 / 1 / 1 | 2 / 1 | B replay snapshot counter=1, no B commit |
| abort-loss | request A, abort A dropped, request B, success B delivered | 2 / 2 / 1 | 2 / 1 | A unknown despite zero A effect |
| body-conflict | request A delta1, success delivered, request B delta2 same scope/key/intent | 2 / 1 / 1 | 2 / 2 | conflict=1; payload_consistent=false; counter1 |
| pending | request A, request B at time20 (past retention10) with A unfinished | 2 / 1 / 0 | 1 / 1 | in_progress=1; unfinished1; pending record1 |
| split-gap | split request A, effect_without_record A dropped, request B | 2 / 1 / 1 | 1 / 1 | indeterminate response1/record1; no completed record; A unknown |
| expiry-equality | request A time0, success time1, request B time11, success time12 | 2 / 2 / 2 | 2 / 2 | expired record1; counter2 |
| before-expiry | request A time0, success time1, request B time10 | 2 / 1 / 1 | 2 / 2 | replay1; no expired record |
| mixed-scope | three accepted/completed requests same key, (C1,O1), (C2,O1), (C1,O2) | 3 / 3 / 3 | 3 / 3 | three independent counters=1 and scoped intents; no conflicts |
| changed-key | A keyK success, B keyJ same intent success | 2 / 2 / 2 | 2 / 2 | declared intent repeat1; key not business intent |
| old-snapshot | A keyK delta1 completes counter1, B keyJ delta2 completes counter3, C keyK delta1 | 3 / 2 / 2 | 3 / 3 | C replay returns counter1; current counter3 |
| null-bypass | atomic null-key A success dropped, null-key B success delivered | 2 / 2 / 2 | 2 / 1 | no records; two bypass accepts |

Invalid: complete replay/blocked/unknown/finished attempt; split gap with delivered=true; gap under atomic/unprotected or any null-key attempt. Late malformed/invalid actions invalidate whole report. Limits are global; 65th request invalid even if scopes differ. Unfinished unprotected work remains active without a dedup record. Zero request trace has zero counts.
